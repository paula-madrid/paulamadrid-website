# paulamadrid.xyz

Paula Madrid's portfolio, rebuilt from the old Readymag site.

- Project text and images: `content/projects.txt` (instructions at the top of the file)
- Home and CV text: top of `build.py`
- Look and layout: `style.css`
- Images: `img/`

After editing, run `python3 build.py` to regenerate the pages, then commit.
